# LVGL v9 Skill

An [Agent Skills](https://agentskills.io) skill for writing, reviewing, debugging, porting, and optimizing LVGL v9 embedded UI code in C/C++, current through v9.6.0.

[![skills.sh](https://skills.sh/b/lordofthesticks0/lvgl-v9-skill)](https://skills.sh/lordofthesticks0/lvgl-v9-skill)

## Install

```bash
npx skills add lordofthesticks0/lvgl-v9-skill
```

Install for a specific agent:

```bash
npx skills add lordofthesticks0/lvgl-v9-skill -a opencode
```

## What's inside

- `skills/lvgl-v9/SKILL.md` — the skill definition with version facts, workflow, bug triage, and a code skeleton.
- `skills/lvgl-v9/references/` — deeper material: migration, performance & memory, porting & display, UI patterns, and debugging & testing.
